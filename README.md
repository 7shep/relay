# Start

A small local-first personal dashboard MVP.

## Run it

```bash
npm install
npm run dev
```

The first pass is intentionally browser-based and follows the terminal-style dashboard reference. It includes a live clock and greeting, weather, focus tasks with progress and quick add, upcoming assignments, pull request status, responsive layout, and reduced-motion support. The data is local placeholder data for now and can later be replaced by Tauri commands and Ollama-backed summaries.
